# PixelGreenhouse

Мод для Forge (Minecraft 1.12.2), добавляющий блок Теплицы для автоматического выращивания априкорнов из Pixelmon. Работа идёт на топливе печки.

## Требования
- Minecraft: 1.12.2
- Forge: 14.23.5.2860 (как в проекте)
- Pixelmon Reforged: 8.4.3 (локальный JAR лежит в `libs/`)
- Java 8 (JDK 8)

## Возможности
- **Блок Теплицы** с GUI и внутренним инвентарём.
- **Рост на топливе**: используется любое топливо печи.
- **Обработка априкорнов**: кладите предметы априкорнов в входные слоты — периодически появляются новые.
- **Поддержка воронок**:
  - Сверху — вход (априкорны)
  - Сбоку — топливо
  - Снизу — выход
- **Ориентация**: блок ставится лицом к игроку.

## Крафт
Рецепт (форменный):
```
GGG
G G
III
```
- `G` — стекло
- `I` — железный слиток
- Результат: `pixelgreenhouse:greenhouse`

## Как использовать
1. Поставьте Теплицу.
2. ПКМ по блоку — откроется интерфейс.
3. Положите априкорны во входные слоты (6 слотов: индексы 0–5).
4. Добавьте топливо в слот топлива (индекс 6).
5. Готовые предметы появляются в выходных слотах (индексы 7–12).
6. Рост занимает время (тик‑система) и даёт небольшое случайное количество за цикл.

## Установка
- Поместите JAR мода в папку `mods` вместе с Pixelmon Reforged 8.4.3.
- Запускайте игру через Forge 1.12.2.
