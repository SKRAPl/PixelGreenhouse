# Настройка GUI для теплицы

## Что было реализовано

✅ **Полная функциональность теплицы:**
- Инвентарь с 13 слотами (6 входных, 1 топливо, 6 выходных)
- Система топлива как в печке
- Автоматическое выращивание апприконов
- GUI интерфейс
- Блок находится в декоративных блоках (без отдельной вкладки)

## Требуется добавить

### Текстура GUI

Вам нужно создать текстуру GUI: `src/main/resources/assets/pixelgreenhouse/textures/gui/greenhouse.png`

**Параметры текстуры:**
- Размер: 256x256 пикселей
- Формат: PNG

**Макет:**
- Основной фон GUI: 176x166 пикселей (верхний левый угол)
- Индикатор горения топлива: 14x14 пикселей на позиции (176, 0)
- Стрелка прогресса роста: 24x16 пикселей на позиции (176, 14)

**Позиции слотов:**
- Входные слоты (слева): 6 слотов в сетке 3x2, начиная с (26, 17)
- Слот топлива (центр): 1 слот на (80, 53)
- Выходные слоты (справа): 6 слотов в сетке 3x2, начиная с (116, 17)
- Инвентарь игрока: Стандартная сетка 9x3, начиная с (8, 84)
- Хотбар игрока: Стандартные 9 слотов, начиная с (8, 142)

**Рекомендация:**
Вы можете использовать текстуру печки из ванильного Minecraft в качестве основы и изменить её под этот макет.

### Текстура блока

Если у вас уже есть текстура блока, поместите её в:
`src/main/resources/assets/pixelgreenhouse/textures/blocks/greenhouse.png`

## Как работает теплица

1. **Входные слоты (слева):** Поместите апприконы, которые хотите выращивать
2. **Слот топлива (центр):** Добавьте топливо (уголь, дерево и т.д.)
3. **Выходные слоты (справа):** Выращенные апприконы появятся здесь
4. **Время роста:** 6000 тиков (5 минут)

## Логика работы

- Теплица потребляет топливо как печка
- Пока есть топливо и апприконы во входных слотах, идёт процесс роста
- Каждые 5 минут из каждого апприкона во входных слотах создаётся копия в выходных слотах
- Входные апприконы НЕ расходуются (они остаются на месте)
- Процесс останавливается, если закончилось топливо или заполнены выходные слоты

## Сборка и запуск

```bash
# Сборка мода
gradlew build

# Запуск в режиме разработки
gradlew runClient
```

Готовый JAR файл будет в папке `build/libs/`

## Структура проекта

```
src/main/java/com/polkax/pixelgreenhouse/
├── PixelGreenhouse.java           # Главный класс с регистрацией GUI Handler
├── blocks/
│   ├── BlockBase.java             # Базовый класс (блок в декоративных)
│   └── BlockGreenhouse.java       # Блок теплицы с открытием GUI
├── container/
│   └── ContainerGreenhouse.java   # Контейнер с логикой слотов
├── gui/
│   ├── GuiGreenhouse.java         # GUI интерфейс
│   └── GuiHandler.java            # Обработчик открытия GUI
├── init/
│   ├── ModBlocks.java             # Регистрация блоков
│   └── ModItems.java              # Регистрация предметов
├── proxy/
│   ├── CommonProxy.java           # Общий прокси
│   └── ClientProxy.java           # Клиентский прокси
├── tileentity/
│   └── TileEntityGreenhouse.java  # TileEntity с инвентарем и логикой
└── util/
    ├── Reference.java             # Константы (без кастомной вкладки)
    ├── IHasModel.java             # Интерфейс для моделей
    └── handlers/
        └── RegistryHandler.java   # Обработчик регистрации
```

## Примечания

- Кастомная вкладка удалена, блок находится в декоративных блоках
- TileEntity автоматически зарегистрирован
- GUI Handler зарегистрирован в preInit
- Локализация добавлена для английского и русского языков
